# Changelog

All notable changes to the VyomQuant SaaS platform are documented in this file.

## [Unreleased]

### Added
- **Strategy Marketplace**: Implemented foundation (`MARKETPLACE_FOUNDATION_IMPLEMENTATION.md`), backend routing, and frontend architecture to support user-published trading strategies.
- **Visual DAG Builder**: Replaced static UI mockups with a fully functional `ReactFlow` node-graph builder (`DAG_BUILDER_IMPLEMENTATION_BLUEPRINT.md`). Includes automated serializers (`DAG_SERIALIZER_IMPLEMENTATION_PLAN.md`) to map UI state directly to backend `pydantic` schemas.
- **QuestDB Telemetry Integration**: Shifted analytics queries off Postgres/Redis and onto high-throughput QuestDB time-series storage (`TELEMETRY_EVENT_SOURCE_MAP.md`).
- **Premium Dashboard**: Added equity curve hydration, live PnL heatmaps, and active bot monitoring powered by WebSocket telemetry streams.

### Changed
- **Unified Execution Engine Architecture**: Extracted the core trading loops from the monolithic FastAPI application into a standalone microservice to securely isolate HTTP traffic from execution (`EXECUTION_ENGINE_ARCHITECTURE.md`). Enabled scaling to support 1,000+ concurrent active users.
- **LLM Provider Abstraction**: Refactored the AI Copilot engine to use an abstract provider layer (`LLM_PROVIDER_ARCHITECTURE.md`), eliminating the hardcoded dependency on OpenAI and allowing dynamic model swapping (e.g., Anthropic, local Llama).
- **Consolidated Backend**: Merged previously duplicated FastAPI apps (and execution/DAG engines) into a single canonical backend, removing dead code and resolving conflicting dependency graphs (`backend_file_list.md`).
- **State Management (Write-Through Cache)**: Refactored the core order tracking system into `state_service.py` to enforce a unified Write-Through Cache (Redis + Postgres) pattern with global idempotency, replacing fragmented state handling.

### Fixed
- **DAG Compiler Logic Execution**: Repaired fatal crashes in the backend mathematical evaluator by fixing Enum mismatches and strictly defining the logic node runtime schemas (`COMPILER_PATCH_PLAN.md`).
- **Authenticated Backtest Sandbox**: Corrected authorization gaps in the DAG Config execution payload to ensure backtests correctly execute strictly within the isolated sandbox environment.
- **Telemetry Reconnect Loops**: Fixed state desynchronization caused by frontend WebSocket disconnections, ensuring the analytics pipeline flushes correctly upon reconnections.

### Security
- **Security Vault Merge**: Formalized the AES-256 Key Vault deployment within the infrastructure layers to prevent credential leaks and protect user API keys (`SECURITY_VAULT_MERGE_REVIEW.md`).
