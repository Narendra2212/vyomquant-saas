# INFORMATION ARCHITECTURE - ALGO22 TERMINAL

## Goal
The user should understand the platform structure within 10 seconds. We are reducing navigation clutter and standardizing terminology.

## Redesigned Navigation Structure

### 1. HOME (Dashboard)
- Top-level metrics (Total Equity, Daily/Weekly PnL, Win Rate)
- Central Equity Curve
- Market Pulse (BTC/ETH/Dominance)

### 2. PORTFOLIO
- Asset Allocation
- Balances
- Recent Executions / Order History
- Performance Analytics

### 3. STRATEGIES
- Strategy List (Active / Paused)
- Strategy Performance metrics
- Create New Strategy (Entry to Builder)

### 4. MARKETS
- Market Pulse (Live Data)
- Fear & Greed Index
- Exchange Status

### 5. AUTOMATION (Strategy Builder)
- Visual ReactFlow Editor
- Templates & Presets
- Execution Preview

### 6. RISK
- Drawdown Monitor
- Kill Switches
- Risk Alert Banner

### 7. PAPER TRADING
- Simulated Environments
- Paper Trading Balance Reset

### 8. ANALYTICS
- Win Rate, Sharpe Ratio over time
- Advanced Reporting

### 9. SETTINGS
- Exchange Connections (API Keys)
- Security Indicators
- Billing & Subscriptions

## Rationale
By grouping related actions and using standard industry terminology (Portfolio, Markets, Automation, Risk), cognitive load is drastically reduced.
